# Distance-based switching of UWB ranging for EV wireless charging alignment: analysis code and data

This repository contains the analysis code and the derived data of the manuscript

> T.-g. Lee, D.-w. Seo, and B.-J. Jang, "Distance-Based Switching of UWB Ranging for Electric Vehicle Wireless Charging Alignment," *Energies* (MDPI), manuscript energies-4704455.

## Folders

- `revision_2026_11/`: code and derived data of the revised manuscript, which reports 39 vehicle trials recorded on 24 November 2026. Its README lists the files behind each table, figure, and section of the manuscript.
- Repository root (`reproduce_table3.py`, `uwb_analysis/`): code of the first submission, kept for reference and described in `FIRST_SUBMISSION.md`. The revised manuscript does not use it. In particular, the revised manuscript calculates the RMSE without removing the mean.
